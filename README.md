# Product Thinking, Start to Finish

A single-page, beginner-friendly summary of the [Institute of Digital Government's Product Thinking learning pathway](https://www.idg.gov.sg/product-thinking/), followed by an 18-question self-assessment quiz.

Built as one self-contained HTML file — no build step, no dependencies. Open `index.html` in a browser.

## What's covered

The seven IDG modules, each rewritten for someone starting from zero:

| # | Module | Frameworks |
| - | ------ | ---------- |
| 1 | Understanding the problem | Three core principles; outputs vs. outcomes |
| 2 | Start with the whys | Five Whys, shown as a worked symptom-to-cause chain |
| 3 | Craft a clear problem statement | The 4Cs — Clarity, Consequence, Cause, Confirmation |
| 4 | Metrics that reflect real outcomes | SMART; leading vs. lagging indicators; Value-Cost Ratio |
| 5 | Assumptions and risks | Market/technical/team risk; the four de-risking stages |
| 6 | A good customer experience | Compulsory-service CX; the 11-star framework |
| 7 | Key takeaways | The three mindset shifts |

## The quiz

Eighteen questions mixing recall and scenario judgement — identifying the missing C in a problem statement, telling a leading indicator from a lagging one, spotting a solution disguised as a problem. Each answer is marked immediately with an explanation, and the results screen breaks down which modules to revisit.
